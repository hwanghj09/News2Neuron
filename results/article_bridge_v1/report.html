기사별 회로 반응까지.

최신 뉴스 점수를 가상 입력으로 변환하고, 실제 FAFB v783 연결을 사용하는 부분 회로에서 기사마다 새로 계산했습니다.

실제 연결 기반뉴런 · 개 연결

출력은 가상 자극을 넣은 계산 모델의 발화율입니다. 초파리가 뉴스를 이해하거나 사람의 스트레스·호르몬 반응을 측정한 결과가 아닙니다. 기사 점수에서 신경 입력으로 바꾸는 함수는 연구 가정이며, 생리 보정된 시각 인코더가 아닙니다.

이번 단계에서 달라진 점

세 단계 결과를 기사에 연결하던 방식에서, 연속적인 R/T/N 점수와 기사별 Poisson 이벤트를 사용하는 새 계산으로 확장했습니다. 같은 양수 점수인 기사도 다른 기사 ID의 입력 난수열을 갖습니다. 회로 대조 조건은 같은 R 이벤트 배열을 그대로 재사용합니다.

R=잔존 위해 지수/100, T=잔존 위협 축, N=부정성. 0점은 입력 0 Hz, 1점은 평균 150 Hz이며, 같은 400ms 안에서 접근 원판의 각도가 변합니다. 신경 입력의 80%는 균일하고 20%는 각도 확장에 따라 변합니다. 세 변환의 차이는 가정한 입력 함수의 차이이기도 합니다.

수치는 먼저 기사별 5개 시드를 평균한 뒤 기사들을 평균했습니다. 총 실행 수를 생물학적 표본 수로 세지 않습니다.

대조·해석의 한계

무작위 입력 세포는 감각 세포형까지 맞춘 대조군이 아닙니다. 차단은 해당 뉴런의 입출력 연결을 제거하는 계산 조작이며 실제 생물학적 억제와 같지 않습니다. 연결 정도 매칭의 남은 오차도 저장했습니다. 부분 회로는 외부 입력과 전뇌 피드백을 생략합니다.

종결 기사에서 R 입력과 출력이 0인 것은 이 모델의 정의와 무입력 휴지 상태에서 따라오는 결과입니다. 부정성과 위험의 차이를 뇌가 이해했다는 증거가 아닙니다. 반복 시드는 계산상의 변동만 나타냅니다. 24건은 AI가 직접 판정한 의도적 균형 표본입니다. 모든 8,128건의 뇌 반응을 계산했다고 해석하지 않습니다.
