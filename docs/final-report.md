# News2Neuron 최종 계산 연구 보고서

작성일: 2026-11-16 · 종료 범위: 실제 뉴스 평가·가상 자극 변환·FlyWire 부분 회로 계산 파일럿

## 최종 결론

**실제 한국어 뉴스의 의미 점수를 가상 입력으로 변환하고 실제 FlyWire 연결 구조에서 반응과 대조 실험을 재현하는 계산 파이프라인을 완성했다. 그러나 뉴스 위험성 평가의 완벽한 정확도, 초파리의 뉴스 의미 이해, 위협 회로의 생물학적 특이성 또는 사람의 스트레스 반응은 입증하지 못했다.**

가장 중요한 실험적 교훈은 대조군 구성이다. 처음에는 GF가 표적 입력에 크게 반응했지만, 대조군의 예측 전달물질·출력까지의 경로·연결 특징을 보강하자 같은 314개 입력에서 차이가 크게 줄었다. DNp06은 정확한 경로·전달물질 층을 맞춘 부분집합에서도 대조군 반응이 더 컸다. 초기 평균 출력의 차이를 위협 회로 특이성의 증거로 단정할 수 없다는 결론이다.

## 1. 데이터와 뉴스 평가

언론사 공식 자료에서 10,000페이지를 확인했고, 본문·날짜 검사를 통과한 8,156건에서 중복 28건을 제거해 **8,128건·8개 매체**를 구성했다. 발행 범위는 2026-08-12~2026-11-09 UTC다. 현재 날짜 기준으로 새로 갱신된 뉴스라고 주장하지 않는다. 후속 정제·연구 제외를 적용한 연구용 자료는 **8,050건**이다.

제목·날짜·원문 URL·HTML/본문 해시·정제·중복·사건 가족·분할을 기록했다. 원문 전문은 공개 결과 묶음에 넣지 않았다. 별도 표시한 합성 기사와 초기 240건 RSS 파일럿은 이 코퍼스에 섞지 않았다.

뉴스 점수는 N(부정성), T(잔존 위협), A(서술의 정서 강도), S/L/I/X(피해 심각도·잔존 근거·시간·범위)를 구분한다. 잔존 위해 지수 R은 사전에 정의한 연구식이다.

```
R = 100 × (S/4) × (L/4) × (0.5 + 0.5×I/4) × (0.8 + 0.2×X/4)
```

이 계수는 자연 법칙이나 실증적 위험 확률이 아니다. 발행 당시 본문 서술의 잔존 위해를 평가하며 사실 검증·현재 독자 개인의 위해·생리 반응을 추정하지 않는다.

현재 실제 기사 직접 AI 판정은 **1,074건**, 나머지 **7,054건**은 유지된 v5 모델 예측이다. 직접 판정과 순수 모델 예측을 출력에서 구분한다. 제목과 정제 본문 해시가 모두 같은 기사 버전에만 판정을 재사용하고, 원장 파일 해시나 중복이 잘못되면 중단한다. 미완성 숫자 초안은 평가 요청에서 차단한다.

여러 개선 후보를 고정된 새 표본과 AI 기준에 비교했으나 v6~v10은 각자의 채택 조건을 충족하지 못했다. 일부 평균 오차나 위험 탐지가 좋아져도 무해 기사 과대평가·낮은 위해의 0점 처리·일치율 저하가 남았다. 실패 자료를 삭제하거나 직접 판정으로 덮어쓴 뒤 정확도 향상으로 계산하지 않았다. 기본 모델은 **v5**를 유지한다. AI는 한 판정자이며 독립 사람 정답 정확도는 미검증이다.

## 2. 뉴스에서 회로 실험으로

최신 8,128건에 R/T/N별 연속 입력 파라미터를 만들었다. 제외 자료는 실행 대상에서 분리했다. 실제 기사 24건은 낮은 부정·위험, 부정적이지만 종결, 잔존 위해의 세 집합에서 매체별 1건씩 고르고 자동 사건 가족이 겹치지 않도록 했다. 기사·설정·코드·입력 표를 실행 전에 봉인했다.

R/100을 주 입력으로, 정규화 T와 N을 별도 비교한다. 점수 0~1을 평균 0~150Hz에 대응시키고, 원판의 등속 접근을 같은 400ms 창 안에 맞췄다. 입력의 80%는 균일하고 20%는 각도 확장에 따른다. 이는 가정한 연결 함수이며 측정된 시각 뉴런의 반응 곡선으로 보정된 관계는 아니다.

회로는 실제 FAFB v783의 **1,367개 뉴런·29,377개 방향성 연결**을 사용한다. 입력은 LPLC2 210개·LC4 104개, 출력은 GF 2개·DNp06 2개다. 최대 3-hop 경로의 유도 부분 그래프이며 전뇌 피드백과 외부 입력을 생략한다. Shiu 상수를 쓰는 별도 축소 LIF 엔진으로, 변경하지 않은 원본 전뇌 예제와 구분한다.

기사별 입력 이벤트를 새로 생성해 **24건×7조건×5시드 840회 + 무입력 5회 = 845회**를 계산했다. 이전 L/M/H 결과 조회는 사용하지 않았다. R 회로 대조들은 이벤트 수·시점·슬롯 배열을 정확히 재사용한다. 같은 기사에서 R/T/N 변환은 입력량이 다를 수 있으므로 동등 입력량 대조로 취급하지 않는다.

## 3. 기사별 실험의 결과

기사마다 5개 계산 시드를 평균하고, 각 집합의 8개 기사를 평균한 출력 ΔHz다. 계산 시드나 뉴런 수를 생물학적 독립 표본 수로 세지 않는다.

| 기사군 | R 입력 | T 입력 | N 입력 |
|---|---:|---:|---:|
| 낮은 부정·위험 | 6.75 | 15.95 | 31.98 |
| 부정적이지만 종결 | 0.00 | 0.00 | 122.16 |
| 잔존 위해 | 85.98 | 103.59 | 106.69 |

종결 기사에서 R/T 입력과 출력이 0이고 N 입력에서 큰 반응이 나오는 것은 변환 정의와 모델 휴지 상태에서 따라온다. 뉴스의 슬픔과 위험을 실제 뇌가 이해했다는 근거가 아니다.

잔존 위해 집합의 R 입력에서 LPLC2 연결 제거는 전체 출력 85.98→23.84Hz, 약 72% 감소를 보였다. LC4 연결 제거는 80.58Hz였고 연결 정도 근사 대조는 85.98Hz였다. 이는 해당 가상 입력과 부분 회로에서 연결 구조가 출력에 영향을 주었다는 계산 결과다. 직접 자극한 뉴런의 연결 제거와 다른 뉴런의 제거가 생물학적으로 동등한 억제라고 가정하지 않았다.

## 4. 대조군 보강 결과

원래 무작위 입력 후보는 전달물질과 출력까지의 경로가 달랐다. 원래 입력 314개는 모두 예측 아세틸콜린 계열이었다. 같은 GF/DNp06 hop 쌍과 전달물질을 만족하는 다른 뉴런이 부족해 이 부분 회로에서 정확한 공통 비교가 가능한 수는 **178개**였다.

뉴런을 중복하거나 지어내지 않고, 314개 유지 근사 비교와 178개 공통 부분집합 비교를 분리했다. 새 실험은 **8건×3조건×5시드=120회**다. 이전 정상·무작위 조건 80회는 재사용으로 표시하고 새 실행 수에서 제외했다. 기사 연계와 대조 보강의 새 계산은 합계 **965회**다. 초기 E0~E9 330회와 민감도·원본 예제 실행은 별도로 보존했다.

**동일한 314개 외부 입력 배열을 사용한 비교**

| 조건 | GF ΔHz | DNp06 ΔHz |
|---|---:|---:|
| 원래 표적 | 166.34 | 5.62 |
| 원래 무작위 | 11.28 | 93.31 |
| 전달물질·경로·연결 특징 근사 대조 | 139.31 | 104.69 |

GF의 표적-대조 차이는 155.06→27.03Hz로 줄었다. 초기 큰 차이에 대조군 구성이 상당한 영향을 주었다. 여러 특징을 함께 바꿨으므로 어느 요인이 얼마의 원인인지는 분리하지 못했다. 근사 비교에서 hop 쌍 일치는 54.14%여서 완전 매칭으로 해석하지 않는다.

**동일한 178개 부분집합 외부 입력 배열을 사용한 비교**

| 조건 | GF ΔHz | DNp06 ΔHz |
|---|---:|---:|
| 선택된 원래 입력 | 104.53 | 21.28 |
| hop 쌍·예측 전달물질이 같은 대조 | 73.34 | 122.47 |

DNp06의 반대 반응은 정확한 층 매칭에서도 남았다. GF와 DNp06을 합친 평균만으로 생물학적 위협 선택성을 결론 내릴 수 없다. 연결 강도·세부 경로·억제성 피드백·수용체와 감각 세포형까지 같은 것은 아니다. 178개에서는 LPLC2/LC4 비율도 달라져 314개 전체를 대표하지 않는다.

## 5. 원래 연구 질문에 대한 판정

| 질문 | 최종 판단 |
|---|---|
| 뉴스 부정성과 잔존 위해를 구분했는가? | AI 기준의 점수·사례 분리와 작동하는 도구를 구현했다. 독립 사람 기준의 정확도·목표 Spearman은 미검증이다. |
| 뉴스 점수를 가상 자극과 신경 입력으로 재현 가능하게 변환했는가? | 구현·실행·검증했다. 생리 보정된 인코더는 아니다. |
| 연결 구조가 모델 출력에 영향을 주는가? | 동일 외부 이벤트를 사용한 연결 제거에서 출력 차이를 확인했다. |
| 위협 회로의 고유 생물학적 특이성이 입증됐는가? | 입증하지 못했다. 대조군 보강으로 GF 차이가 줄고 DNp06 반대 반응이 남았다. |
| 실제 초파리 활동과 일치하는가? | 공개 자료 메타데이터·연동 코드는 확인했으나 원영상/칼슘 시계열 재분석은 미수행이다. |
| 사람의 스트레스·호르몬·불안이 설명되는가? | 사람 대상 측정이 없으므로 판단할 수 없다. |

## 6. 완료된 산출물과 검증

최신 전체 점수 CSV/Parquet, 카탈로그 명세, 모델 선택 이력, 새 기사별 실험과 보강 대조의 원래 이벤트·스파이크·지표·뉴런 ID·해시, 대화형 보고서, 실행 CLI, 최종 요약과 결과 묶음을 제공한다. 초기 원고·단계별 실패·옛 보고서는 보존했다.

전체 테스트는 **140개**다. 물리 자극·Poisson 입력·정확한 이벤트 재사용·세포 매칭·가족 분할·기사 버전 판정 재사용·잘못된 입력·작은 고정 회로의 Brian2 수치 비교를 검사한다. 최종 감사는 저장된 원자료를 재계산하고 대표 네트워크 실행의 스파이크 시점·ID를 재현한다. 감사 재실행은 새 실험 수에 더하지 않았다.

최종 재현 검사 결과는 [검증 원장](../results/final_release/validation/summary.json)에 기록한다. [최종 결과 모음](../results/final_release/index.html)에서 최신 점수와 보고서를 내려받을 수 있다. 원문·대용량 특징 캐시는 결과 묶음에서 제외했다. 전체 뉴스 원응답 재추출 감사에는 기존 개인 캐시가 필요하며 공개 코드·회로 실험 감사와 구분한다.

## 종료 판단

이번 작업은 **재현 가능한 계산 파일럿으로 완료**한다. 현재 성능의 자동 뉴스 평가를 완벽하거나 사람 정답에 검증된 시스템으로 배포하지 않는다. 실측 신경 활동·생리 인코더·독립 사람 평가·인간 생리 실험은 별도 실증 연구가 필요한 미수행 항목이다. 추가 데이터를 확보하지 않고 그 항목을 검증 완료로 바꾸지 않는다.

최종적으로 확보한 것은 “뉴스 점수와 특정 가상 입력을 연결했을 때, 선택된 실제 연결 구조에서 어떤 반응이 생기며 대조군을 바꾸면 결론이 어떻게 달라지는가”에 대한 투명하고 재현 가능한 계산 결과다.

## 최종 검증 다시 실행하기

```bash
# 공개 저장소 자료로 가능한 코드·기사별 회로·보강 대조 검사
python scripts/final_validation.py --out results/my_public_validation

# 원래 기사/특징/원본 모델 캐시가 있는 환경에서 전체 8종 감사
python scripts/final_validation.py --full --out results/my_full_validation

# 이미 배포된 최종 파일과 ZIP 내부 해시 검사
python scripts/build_final_report.py verify
```

새 검증 출력 폴더를 지정한다. `--full`은 원래 개인 캐시가 필요하며 공개 자료 검사만 통과한 것을 전체 8종 감사로 표시하지 않는다. 결과 묶음은 보고서·최신 점수·원장·검증 기록·새 두 회로 실험 원자료를 포함하고 전체 개발 저장소를 대신하지 않는다.
