# 최근 90일 대규모 한국어 뉴스 자료 처리 — v2

## 범위와 사전 기준

사용자가 선택한 범위는 최근 90일 한국어 뉴스다. 이번 실행의 고정 기간은 **2026-08-12~2026-11-09 UTC**다. 공개 매체별 날짜·월별 사이트맵 및 최근 기사 피드로 후보를 찾는다. 매체의 접근 규칙을 확인하고 제한 응답을 우회하지 않는다. 수집기 식별자는 `ChatGPT-User News2NeuronResearch/0.2`이며 검색엔진이나 일반 사용자인 척하지 않는다.

발견한 URL, 확인을 시도한 페이지, 실제 본문·날짜를 통과한 기사, 중복 제거 후 기사 수를 각각 보고한다. **URL 목록을 본문이 검증된 기사 수로 세지 않는다.** 후보 표본은 12,000개, 페이지 확인 목표는 10,000개, 최종 고유 기사 최소 목표는 3,000개다. 출처별 제공 기간 차이가 있어 확률표본·한국 뉴스의 대표표본이라고 부르지 않는다.

고정 기준은 `configs/corpus_v2.yaml`에 보존한다. 초기 6,500페이지 확인 계획을 10,000페이지로 확장한 이력은 별도 파일에 기록하며 출처·기간·품질 문턱·점수 기준은 바꾸지 않는다. 추출기 개발 과정에서 발견한 오염과 수정은 원래 응답 캐시를 유지한 채 전량 다시 처리한다.

## 기존 240건의 감사 결과와 용도

초기 자료는 3개 매체의 제목·짧은 RSS 발췌문 240건이었다. 발췌문 평균 길이는 약 68자였고, 195건은 80자보다 짧았다. 종합·헤드라인·클로징 표기가 있는 자료도 16건이었다. 독립 사람 정답은 없고, 그때 기록한 Codex 판단 역시 검증 전 파일럿 점수다.

따라서 초기 240건의 점수를 새 자료에 복사하거나 학습 정답으로 사용하지 않는다. 새 자료의 본문 검증·중복·분할은 텍스트와 날짜만으로 처리하며 N/T/A 점수를 보지 않는다. 초기 자료와 보고서는 역사적 파일럿으로 따로 보존한다.

## 원자료 보존과 기사 식별

- 모든 응답은 URL·HTTP 상태·실제 도착 URL·수집 UTC·응답 SHA-256과 연결한다. 원문 응답과 정제 본문은 공개 Git에서 제외한 캐시에 보관한다.
- 광고 추적 인자만 제거하고 `newsId`, `news_id`, 매체별 기사 키를 보존한다. 확인하지 않은 HTTP 주소를 임의로 HTTPS 기사로 간주하지 않는다.
- 출처가 제공한 canonical URL도 허용된 동일 매체 도메인 안에서만 사용한다. 외부 리다이렉트와 제한 응답은 기록하고 보류한다.
- 같은 canonical 기사에서 서로 다른 스냅샷이 발견되면 기사 버전으로 묶는다. 각 원래 응답은 그대로 보존한다.
- 원문 전체는 배포하지 않는다. 공개 스냅샷은 제목과 짧은 발췌 합계 25개 공백 단위 단어 이내, 원문 URL, 구조·품질 지표 및 해시를 제공한다. 발췌는 연구자가 쓴 요약이라고 표시하지 않는다.

## 발행일·수정일·수집일을 구분

기사 JSON-LD의 `datePublished`와 기사 메타데이터를 우선 사용한다. 초 단위 시각이 있는 기사 근거를 날짜만 있는 근거보다 우선한다. 기사 페이지에 근거가 없을 때만 출처의 news sitemap 발행 시각을 명시적으로 사용한다. **사이트맵 lastmod, HTTP Last-Modified, URL의 숫자는 발행 시각으로 승격하지 않는다.** URL 날짜는 후보 표본 구성과 불일치 점검에만 사용한다.

시간대 없는 국내 매체 시각은 KST를 가정했음을 플래그에 남긴다. 날짜만 있고 시각을 확인할 수 없는 자료는 자정으로 꾸며 넣지 않고 보류한다. 미래 시각, 90일 밖의 자료, 기사 내부 발행 시각끼리의 큰 충돌도 보류한다. 기사와 사이트맵 간 시각 차이는 조용히 고치지 않고 별도 플래그로 남긴다.

`dateModified`는 발행일과 별도 저장한다. 학습·검증 경계를 넘어서 수정된 것으로 명시된 기사는 과거 본문인 것처럼 학습에 넣지 않는다. 수정 시각이 없는 기사는 그 사실을 표시한다. **현재 수집한 본문이 과거 발행 당시와 완전히 같다고 보증할 수 없으므로, 발행일 기준 분할만으로 엄격한 과거 시점 백테스트가 성립했다고 주장하지 않는다.**

## 본문 추출과 품질 문턱

매체별 실제 HTML 구조 또는 매체가 제공한 구조화 기사 본문만 사용한다. 일반 페이지 전체를 텍스트화해 기사로 간주하지 않는다. News1은 공개 페이지의 구조화된 `contentArrange`에서 `text` 항목만 읽는다. 다른 매체는 확인한 본문 요소를 사용하며 구조화 `articleBody`를 대안으로 둔다.

스크립트·광고·공유 버튼·사진 설명·표·자동 요약·관련 기사 카드·구독 UI·독립된 이메일/태그/저작권 꼬리말을 분리한다. 원래 HTML은 유지하고 분석용 서술 본문만 정제한다. 제목과 본문 앞뒤를 매체별 3건씩 점검한 24건의 AI 품질 표본에서 발견한 오염을 추출 규칙에 반영했다. 이 표본 검토는 독립 사람의 검수나 전문 전체의 정확도 측정이 아니다.

최소 400자, 한글/영문 문자 중 한글 비율 0.5 이상, 최소 서술 문장 수를 사용한다. 비정상적으로 긴 본문, 접근 제한 본문, 표/순위/종합 헤드라인, 짧은 영상 소개 등은 보류한다. 이 기준은 실용적인 품질 문턱이며 모든 저품질 기사를 판별하는 검증된 분류기는 아니다. 보류 사유와 모든 원래 후보를 보존해 과잉 제외도 검수할 수 있게 한다.

## 중복과 사건을 따로 처리

1. 같은 기사 URL의 버전, 완전히 같은 정규화 본문, 제목과 본문이 모두 매우 유사한 재송고를 구분한다.
2. 같은 제목이라는 이유만으로 다른 본문을 삭제하지 않는다. 수치가 달라진 후속 보도는 자동 중복 제거에서 보호한다.
3. SimHash 후보와 실제 본문 겹침을 함께 확인하고 중복 쌍과 대표 기사 ID를 기록한다.
4. 별도의 사건 후보는 문자 특징의 가까운 이웃과 제목 토큰 겹침으로 찾고 전체 그룹의 최대 시간 폭을 72시간으로 제한한다. 큰 밀집 N×N 행렬을 만들지 않고 블록 단위로 처리한다.
5. 이 묶음은 의미적 사건 동일성의 정답이 아니다. 과하게 합치거나 놓칠 수 있으며 후보 쌍을 독립 검수용으로 제공한다.

## 분할과 표본 편향

학습은 10월 11일까지, 검증은 10월 12~25일, 테스트는 10월 26일 이후다. 같은 사건 후보가 경계를 넘으면 해당 그룹을 경계 보류로 분리한다. 명시된 수정 시점이 다음 구간으로 넘어가는 기사도 별도 보류한다. 계산한 그룹 ID가 분할 사이에 겹치지 않는지 전량 확인하되, 자동 묶음이 놓친 의미적 누출까지 0이라고 주장하지 않는다.

모든 품질 통과 자료를 보존하고, 그중 연구용 부분집합에는 매체별 최대 25% 비중과 경계 보류·협찬 의심 자료 제외를 적용한다. 매체×날짜 교차표와 결측 날짜를 그대로 공개한다. 매체의 native section은 감정·위협성 정답이 아니며, 분류를 못 찾으면 미분류로 남긴다.

## 평가의 현재 위치

전체 정제 본문에 단어 규칙 baseline을 적용해 진단용 파일을 만든다. 긴 본문일수록 단어가 나타날 기회가 많으므로 점수의 길이 편향과 문맥·부정문 문제를 후속 점검해야 한다. 이 값은 의미를 검증한 대규모 LLM 평가나 사람 정답이 아니다. 새 자료에 임의의 AI 정답을 채우거나 기존 240건의 판단을 전이하지 않는다.

품질검수는 통과 자료뿐 아니라 보류 자료와 제거된 중복도 표본으로 뽑는다. 사람 평가 후보는 서로 다른 사건 후보에서 선택하고, 점수와 규칙 출력을 숨긴 독립 3인 빈 양식을 제공한다. 빈 양식은 완료한 사람 평가로 세지 않는다. 실제 독립 평가 후에만 일치도·정확도·임계값·분류별 성능을 검정한다.

이 단계에서는 뉴스 점수로 새 생물학적 결론을 만들지 않는다. 정제 보고서, 기사별 제외 원장, 중복·사건 후보 쌍, 분할, 출처·날짜 분포와 재현 가능한 해시가 산출물이다.
