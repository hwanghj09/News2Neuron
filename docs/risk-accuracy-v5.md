# 위험성 수치화 추가 개선: v4·v5

기존 198건에 실제 기사 160건을 더 읽어 **직접 AI 판정을 358건**으로 늘렸다. 사람 판단을 기다리는 단계는 없다. 모든 점수는 기사가 발행 당시 제시한 잔존 위해를 평가하는 같은 Codex 세션의 기준이며, 독립 사람 정답이나 실제 위해 발생 확률은 아니다.

## 무엇을 고쳤는가

v3는 S/L/I/X의 예측 평균을 곱해 위험 지수를 만들었다. 위험이 큰 상황과 위험이 없는 상황이 섞이면, 축별 평균을 곱한 값이 각 상황의 위험 지수를 직접 추정한 값보다 크게 낮아질 수 있다. v4에서 지수 직접 회귀를 시험했다.

v4는 큰 오차 일부를 줄였지만 일반 기사의 오탐이 늘었다. 당시 새 평가 자료를 개발용으로 전환하고, 별도의 새 표본을 선정해 v5를 평가했다. 같은 시험 자료를 계속 튜닝하면서 새 테스트 성능이라고 표시하지 않는다.

v5는 다음을 보강했다.

- 제목·본문 선두·본문 말미·전체에서 종결, 진화, 미해결 구조, 현재 부상·활동 제한, 예방훈련, 법적 과거 사건을 구분하는 학습 특징.
- 잔존 위해가 없다는 AI 기준을 구분하는 학습된 분류기와 0~100 지수 직접 회귀. 단어 하나로 위험을 강제로 0으로 만드는 규칙은 아니다.
- 같은 사건·작전의 후속 기사를 묶은 교차검증과 사건군별 균형을 반영한 모델 선택. 가족별 학습 가중치 옵션도 비교했으나 최종 선택은 그 옵션을 사용하지 않는다.
- 학습은 321건, 8개 매체다. 새로운 32건의 판정과 예측을 열기 전에 모델·입력·예측 해시를 고정했다.

32개 설정 조합을 개발 자료의 사건군별 4분할 교차검증에서 비교했다. 최종 선택은 SVR `C=8, gamma=0.25`, 학습된 무위험 구분기 사용, 수동 하한 절단 없음이다. 최종 새 표본의 결과를 보고 모델이나 임계값을 바꾸지 않았다.

## 같은 새 표본의 결과

새 32건은 매체별 무작위 2건과 점검용 2건으로 뽑았다. 기사 내용을 읽으며 기존 학습 자료와 같은 사건의 후속 보도 5건을 추가로 확인했다. 모델 점수를 보기 전에 이를 표시했고, 주 비교는 나머지 27건이다. 32건 전체의 민감도 결과도 공개한다. 이 과정이 모든 의미적 사건 관계를 발견했다고 주장하지 않는다.

| 모델 | 주 비교 27건 MAE /100 | 무작위 16건 MAE | 점검용 11건 MAE | 10점 이내 AI 일치율 |
|---|---:|---:|---:|---:|
| v3 고정 기준 모델 | 11.10 | 5.35 | 19.46 | 55.6% |
| v4 직접 회귀 후보 | 11.98 | 7.97 | 17.82 | 63.0% |
| v5 무위험 구분 보강 | 10.15 | 5.11 | 17.48 | 51.9% |

v3 대비 v5의 평균 절대오차는 약 **8.5% 감소**했다. 무작위 기사와 어려운 기사 양쪽에서 평균 오차는 감소했지만, 10점 이내 일치율은 하락했다. 큰 오차 감소와 임계값 근처의 일치율이 같은 방향으로 움직이지 않으므로 모든 지표가 좋아졌다고 표현하지 않는다.

짝지은 표본 재추출에서 평균 오차 감소의 95% 백분위 범위는 약 **−1.63~3.42점**이다. 작은 동일 AI 표본의 기술 통계이며 0을 포함한다. 미래 뉴스 전체나 독립 사람 정답에 대한 우월성이 통계적으로 입증됐다는 뜻이 아니다. 이전 v3의 9.23점은 다른 표본의 결과라 이번 수치와 직접 비교하지 않는다.

## 점수와 재현

`data/risk/20261109_v5/news_risk_scores.csv`는 전체 8,128건의 새 점수다. 직접 읽은 358건은 `direct_Codex_session_judgment`, 나머지 7,770건은 `AI_supervised_v5_model_prediction`으로 구분한다. 학습 321건·새 평가 32건·연구용에서 제외된 짧은 본문 직접 판정 5건을 합쳐 358건이다.

직접 판정은 S/L/I/X의 기존 기준식으로 지수를 계산한다. 모델은 그 기준 지수를 직접 학습하며, 보조 축 평균으로 계산한 `component_index`는 별도로 제공한다. 두 값을 같은 것으로 설명하거나 실제 위험 확률로 표시하지 않는다. N/T/A는 계속 0~1 정규화 열을 제공한다.

본문과 특징 캐시는 Git에서 제외한다. 고정 응답 캐시가 있는 작업환경에서 다음 검증을 실행한다.

```bash
python scripts/audit_risk_accuracy.py
python -m pytest -q
```

검증은 전체 본문 해시, 모델 예측 재현, 직접 판정과 모델 출력의 구분, 새 평가와 개발 ID 분리, CSV/Parquet 수치 일치, 평가 지표 재계산을 포함한다. 이는 처리와 계산의 검증이다. 뉴스 사실이나 판단 의미의 완전한 정확도 검증과 구분한다.

v3·v4·v5의 원래 예측과 판정 원장은 모두 보존한다. 후속 학습은 현재 시험 자료를 새 테스트로 재사용하지 않는 새 실험 버전에서 진행한다.
