# 새 기사·합성 사례 직접 테스트와 정정

실제 기사 32건과 직접 작성한 합성 기사 64건을 추가로 읽고 비교했다. 실제 기사는 저장된 90일 코퍼스에서 이전에 판정하지 않은 다른 기사이며 이번에 새로 다운로드한 기사는 아니다. 7개 매체를 포함한다. SBS는 기존 판정과 관련 사건을 제외한 뒤 3건만 남아 이 표본에서 제외했다.

**실제 기사 32건의 직접 AI 판정을 새 배포본에 반영했고, 위험 지수가 달라진 기사는 10건이다.** 나머지 기사도 축·상태·근거를 기록했다. 누적 실제 기사 직접 판정은 1,032건이다. 합성 64건은 실제 뉴스나 이 직접 판정 원장에 넣지 않았다.

## 기대 판정과 평가 분리

모델 결과를 보기 전에 제목과 정제 본문 전체를 읽고 N/T/A/S/L/I/X·상태·근거를 작성했다. 기대 판정과 표본을 `389886e`에 먼저 커밋했다. 실제 32건은 개발 16·확인 16, 합성 64건은 개발 32·확인 32로 나눴다. 합성 시나리오 가족은 양쪽에 겹치지 않고, 실제 기사 가족은 기존 1,000건 판정 및 서로 다른 기사와 겹치지 않도록 자동 연결 그룹을 제외했다. 이것이 모든 의미적 사건 관계를 완벽하게 찾았다는 뜻은 아니다.

이전 사용 가능 판정 995건과 새 개발 48건만 학습·4중 사건 그룹 교차검증에 썼다. 최종 모델·소스·해시를 `1460649`에 고정한 다음 확인용 48건의 예측을 열었다. 이후 후보의 가중치·특징·임계값을 바꾸지 않았다. 판정자와 개발자는 같은 AI이므로 독립·맹검 사람 평가가 아니다. 합성 기대값은 기능 명세이며 실제 뉴스 정답 정확도가 아니다.

## 고친 입력 문제

양자화된 E5 인코더는 제목 배치 안의 다른 제목에 따라 수치가 달라졌다. 8개 매체의 기사로 비교했을 때 제목 특징의 최대 차이는 0.0199903이었다. 기존 16개 제목 배치를 재현하면 저장 특징과 차이는 0이었고, 본문·문맥 특징도 차이가 0이었다.

새 입력 경로와 v8 학습은 제목을 한 개씩 처리한다. 같은 기사를 단독 또는 다른 기사와 함께 넣어도 특징이 정확히 같다. 본문은 256토큰 창·32토큰 겹침으로 끝까지 처리하고 해시·창 수를 남긴다. 긴 본문 끝의 위해 문장을 추가하는 테스트도 통과했다. 원래 v5 모델·저장 특징은 보존했다. 후보 비교의 v5는 같은 새 입력 특징에서 고정된 v5 가중치를 실행한 순수 출력이다. 아래 정정 표의 이전 값은 원래 배포본 값이어서 제목 배치 수치 차이로 후보 비교 값과 조금 다를 수 있다.

누락 본문, HTML, 미완성 숫자 초안은 점수를 만들기 전에 거부한다. 기사에 적힌 AI 지시문과 입력 JSON의 기대 점수는 판정을 실행하는 지시나 정답으로 사용하지 않는다.

## 최종 확인용 결과

단위는 100점 지수의 절대오차이며 직접 판정으로 덮기 전 순수 모델을 비교했다.

| 확인 집합 | 모델 | 평균 절대오차 | 10점 이내 일치 | 기준 30점 이상 탐지 |
|---|---|---:|---:|---:|
| 실제 16건 | 기존 v5 | 3.78 | 13/16 | 1/1 |
| 실제 16건 | v8 후보 | 7.25 | 9/16 | 1/1 |
| 합성 32건 | 기존 v5 | 23.67 | 15/32 | 3/16 |
| 합성 32건 | v8 후보 | 18.36 | 7/32 | 13/16 |

결과를 연 뒤 별도로 계산한 보조 지표로, 합성 확인 16쌍에서 위험이 남은 기사의 점수가 종결·가상 기사의 점수보다 높은 쌍은 7/16에서 16/16으로 늘었다. 동점은 성공으로 세지 않았다. 그러나 위험의 **순서**를 잘 구분하는 것과 **절대 점수**가 맞는 것은 다르다. 종결·모의 상황에도 10~27점가량을 주는 오류가 늘어 10점 이내 일치율은 악화했다. 실제 확인 16건 중 고위험은 1건뿐이므로 높은 탐지율을 일반화할 수도 없다.

v8은 별도 의미·문맥 커널과 문자 특징, 치료·재활·미반환·완료·훈련/실제 사고의 문맥을 학습했다. 개발 교차검증으로 후보를 선택했으나 최종 실제 기사 평균 오차와 일치율 보존 조건을 통과하지 못했다. **기본 모델은 v5를 유지했다.** 합성 평균 오차 개선이나 순서 성공을 전체 뉴스 정확도 향상으로 포장하지 않는다.

## 실제 기사에 적용한 정정 예

다음은 AI가 직접 내린 판정의 적용이며 학습 모델의 새로운 정확도 증거가 아니다.

| 기사 | 이전 배포 점수 | 적용한 직접 AI 점수 | 판정 근거 |
|---|---:|---:|---|
| CNN 동승 취재 차단 | 0.0 | 39.4 | 법원 결정 뒤에도 실제 취재 접근 제한이 지속됨 |
| 제조업 생산 증가·일부 업종 고용 감소 | 0.0 | 19.7 | 긍정적 제목 속 소매 판매·취업자 감소 통계도 반영 |
| 알뜰폰 사업자 조사 장기화 | 0.0 | 16.9 | 영업 지속과 제재 이력을 반영하되 새 위반 확정은 피함 |
| 골프 우승·다른 선수 내년 시드 상실 | 0.0 | 15.9 | 우승 감정과 별도로 실제 참가 제약이 남음 |
| 외도 심리 기사 속 기밀 유출 의혹 | 17.4 | 8.4 | 과거 사례와 현재 미확인 의혹을 구별함 |

직접 판정 카탈로그는 **제목과 정제 본문 SHA-256이 모두 같은 버전**에만 재사용한다. 기사 ID·입력에 적힌 해시·기대 점수로 판정을 가져오지 않는다. 본문이나 제목이 달라지면 기존 모델 예측으로 돌아간다. 출력의 `prediction_kind`로 직접 AI 판정과 순수 모델 예측을 구분한다. 알려진 판정을 그대로 표시한 뒤 오차 0을 정확도로 보고하지 않는다.

기존 8,128건과 연구 포함 여부는 유지했다. 미판정 7,096건의 저장 모델 출력도 그대로다. 숫자가 미완성인 방송 초안 1건은 기존처럼 격리하며, 직접 판정 재사용 경로에서도 점수를 내보내지 않는다.

## 남아 있는 오류

확인용 합성 사례에서 실제 가스 누출은 기대 85.0 대비 후보 33.6, 터널 붕괴 실종은 85.0 대비 41.5였다. 정전 복구·보상 완료는 기대 0 대비 26.6, 가스 센서 오경보는 0 대비 23.4였다. 배우의 현재 재활·배구 선수 결장도 여전히 낮게 평가했다. 이 사례를 결과를 본 뒤 학습하거나 평가에서 빼지 않았다. 모든 실패는 결과 CSV에 남았다. 새롭고 미판정인 기사까지 해결됐다고 주장하지 않는다.

## 실행과 검증

```bash
# 먼저 고정 인코더 설치: 필요 시 pip install -e '.[risk]'
python scripts/download_risk_encoder.py

# 정제 본문 JSONL: 한 줄마다 title, body, 선택적 case_id/origin
# 정확히 일치하는 실제 기사 판정 재사용 + 나머지는 기본 v5 모델
python -m news_flywire.risk_review_updates my_articles.jsonl --output my_scores.jsonl

# 직접 판정을 쓰지 않는 순수 모델 경로
python -m news_flywire.risk_inference my_articles.jsonl --output pure_scores.jsonl

# 실패 후보는 연구 비교 목적으로만 명시적으로 실행
python -m news_flywire.risk_inference my_articles.jsonl \
  --model data/risk/20261110_v8/model.joblib --output candidate_scores.jsonl

# 저장된 결과 재현·해시·분할·공개 입력 경로 검사
python scripts/audit_new_article_diagnostics.py
python scripts/audit_followup_release.py
python -m pytest -q
```

기존 환경의 원문·특징 캐시는 Git에서 제외했다. 판정 기대값, 합성 전문, 선택 명세, 학습 계획·교차검증, 고정 모델, 순수 확인 예측, 기사별 정정, 정확 버전 판정 카탈로그는 제공한다. 단계별 준비·학습은 `scripts/new_article_diagnostics.py`에 있으며 봉인 자료나 열어 본 최종 확인 자료를 덮어쓰려 하면 중단한다.

검증 결과는 전체 테스트 105개 통과다. 최종 확인 예측 48건을 재생성해 차이 1e-8 미만, 공개 입력 경로로 실제·합성 4건을 다시 인코딩해 저장 특징과 1e-6 미만 차이를 확인했다. 판정 재사용은 초안 1건을 제외한 실제 1,031건을 검증했다. 명령행에 실제 32·합성 64건을 넣어 실제만 직접 판정, 합성은 모두 순수 모델 출력으로 표시되는지도 확인했다. 이 검사는 적용·재현 무결성이며 새 정확도 평가가 아니다.
