# 데이터 및 사람 연구 범위

현재 파이프라인은 계산 연구다. 참여자를 모집하거나 뉴스를 노출하거나 생체 신호를 수집하지 않는다. `data/sample_news.csv`는 직접 작성한 가상 요약이며 실제 기사 또는 실제 사람의 응답을 흉내 낸 자료로 사용하지 않는다.

실제 뉴스는 ID·출처·URL·발행일·직접 작성한 요약 또는 재배포 허가 텍스트를 사용한다. 원문 수집에 적용되는 서비스 약관을 확인하고 동일 사건·재송고를 묶는다. raw 디렉터리와 개인 평가 자료는 공개 Git에서 제외한다.

선택적 사람 연구는 기관의 윤리 검토, 성인 동의, 철회 및 자료 폐기 절차, 익명화와 표본 수 근거를 확보한 뒤 별도로 수행한다. 미성년자 참여는 해당 기관의 보호자 동의와 절차를 따른다. 개인적 관련성·기저 상태·노출 순서를 별도 기록한다. 심박·각성·긴장·코르티솔을 같은 변수로 취급하지 않는다.

공개 FlyWire 연결은 한 개체의 구조다. DANDI의 칼슘 활동 자료는 다른 개체·상태·관측 방식에서 나온다. 공개라고 해서 뉴런 ID를 일대일로 대응시킬 수는 없다. 비교 수준과 출처를 명시한다.
