# v7 사전 검증과 최신 점수 배포

v7은 정확도 개선 입증에 실패했다. 결과를 보고 모델을 다시 맞추거나 표본을 늘리지 않았다. [최신 보고서](../data/risk/20261110_release/report.html)는 기존 v5 예측에 누적 직접 AI 판정 1,000건을 적용한다. v6·v7 후보는 비교 가능하도록 모두 보존하며 기본 모델로 채택하지 않는다.

## 같은 새 기사에서 확인한 결과

| 표본 | 모델 | 평균 절대오차 | 10점 이내 AI 일치 | 30점 이상 위해 재현율 |
|---|---|---:|---:|---:|
| 무작위 280건 | v5 | 9.20 | 69.3% | 4.7% (2/43) |
| 무작위 280건 | v6 | 8.55 | 70.0% | 9.3% (4/43) |
| 무작위 280건 | v7 | 8.98 | 70.4% | 16.3% (7/43) |
| 무작위 280건 | 항상 0 | 11.90 | 62.9% | 0% |
| 어려운 42건 | v5 | 18.55 | 33.3% | 46.9% (15/32) |
| 어려운 42건 | v6 | 14.98 | 47.6% | 100% (32/32) |
| 어려운 42건 | v7 | 16.24 | 31.0% | 75% (24/32) |

주 평가는 무작위 280건이다. 어려운 42건 및 전체 322건을 합친 수치를 주 지표로 바꾸지 않는다. 위 수치는 직접 판정으로 덮기 전 순수 모델 예측이다. 30점은 연구용 임계값이며 실제 위해 확률과 관계없다. 주 표본의 높은 위해 누락이 여전히 크므로 이 모델을 검증된 경보 시스템으로 해석할 수 없다.

같은 기사 쌍을 매체별로 20,000회 재표집한 평균 오차 감소의 **97.5% 백분위 범위**는 다음과 같다. 두 번째 확인 시도여서 이전 95%보다 엄격한 범위를 미리 정했다.

| 비교 | 평균 오차 감소 | 97.5% 범위 |
|---|---:|---:|
| v5 → v7 | +0.217점 | −0.702~1.152점 |
| v6 → v7 | −0.428점 | −1.244~0.392점 |

둘 다 0을 포함한다. 10점 이내 일치율의 점추정은 개선됐지만 통계적 개선이라고 말할 수 없다. 높은 위해 재현율과 보조 평가 MAE의 비악화 조건도 실패했다. v6의 이전 새 128건 평가 역시 v5 대비 MAE 7.77→7.07점이었지만 95% 범위 −0.54~1.94점으로 입증 기준을 통과하지 못했다. 이전 실패는 [v6 결과](risk-evidence-v6.md)에 그대로 남긴다. 반복 실험을 전체적으로 통제한 단일 유의확률이나 독립 반복 검증 성공을 주장하지 않는다.

## 모델을 고정한 과정

1. `db2b12c`: v6 실패 결과와 v7 프로토콜·표본을 커밋했다. v6에서 이미 본 판정은 모두 개발용으로 전환했다.
2. 개발 673건에 사건군별 5분할 교차검증을 적용했다. v6의 자동 사건군에 미리 발견한 관련 관계를 병합했다. 본문 전체 의미 특징에 치료·결장·복구·미회수 금융 피해·종결·부정 등 문맥 특징 72개를 추가했다. 단어 규칙으로 점수를 직접 지정하지 않는다.
3. 문자 TF-IDF와 의미 커널 회귀 및 문맥 트리의 혼합을 개발 자료에서 선택했다. 높은 위해 누락에 대한 비용과 새 전체 본문 판정의 학습 가중치를 늘렸다. 최종 선택은 트리 25%, 커널 75%였다. 모든 후보 및 선택 손실은 `training.json`에 있다.
4. `e67c489`: 학습 코드, 모델, 모든 예측, 특징과 표본 해시를 고정했다. 새 평가 라벨 사용은 0건이었다.
5. 예측 점수를 열지 않고 새 322건의 저장된 정제 본문 전체를 현재 Codex가 읽어 7개 축·상태·근거를 직접 판단했다. 이 판정을 규칙으로 생성하거나 사람 평가로 표시하지 않았다.
6. `4ef8f25`: 모든 322건 판정과 패킷 해시, 추가 관련 사건 관찰을 봉인했다. 그 뒤 고정 예측을 열어 비교했다.

8개 매체가 학습에 포함됐지만 확인 평가 모집단은 **7개 매체, 매체별 무작위 40건**이다. SBS는 이미 판정한 사건군 제외 후 적격 새 기사가 4건만 남아 주 평가에서 제외했다. 보조 표본은 각 매체별 v6 고득점 후보 중 미판정 사건군 6건이다. 이 표본이 전체 뉴스나 미래 보도를 대표한다고 주장하지 않는다. 자료는 2026-08-12~11-09 고정 코퍼스이며 재수집으로 비교 입력을 바꾸지 않았다.

## 본문과 기준의 한계

발행 당시 본문에 서술된 남은 위해를 평가한다. 회고·훈련·허구·의혹·치료 중 상태를 구분한다. 익명 사연과 당사자 주장은 그 불확실성을 남긴다. 예를 들어 긍정적 스포츠 기사 속 수술 회복 대기는 반영하고, 암이 아니라는 정밀검사 결과를 암 확진으로 바꾸지 않는다. 사망을 회고하는 기사에서 추가 사망을 추정하지 않는다. 개인정보 유출의 진입점이 차단됐어도 이미 노출된 정보의 악용 가능성은 구별한다.

정확한 현재 AI 모델 스냅샷과 decoding 설정은 노출되지 않았다. 판단자는 현재 세션 AI 한 명이며 독립 사람 평가자는 0명이다. 같은 AI의 판단과 재표집을 독립 평가자로 세지 않는다. AI 기준 자체의 진실성, 사람 판단과의 일치, 미래 도메인, 위험 발생 확률은 검증하지 못했다. 뉴스가 실제 매체에서 수집됐다는 사실이 기사 주장까지 사실 확인됐다는 뜻은 아니다. 매체가 생성형 AI로 작성했다고 밝힌 기사는 그 출처 표시를 원자료에 보존했다.

자동 사건군 분리 뒤에도 일부 후속·연관 기사가 남았다. 김성수 후보자, 수원 승격·삼성 한국시리즈, 배달앱 과징금, 젠슨 황 의혹, 이란·우크라이나 전쟁 등의 관계를 **예측 개봉 전** 따로 기록했다. 주 표본은 변경하지 않았다. 알려진 개발 관련 주 기사 10건을 제외한 보조 분석은 270건이며, 전체 280건에 대한 알려진 캠페인 단위 군집 재표집도 별도 제공한다. v6에는 같은 방식의 알려진 관련 기사·미완성 원고 민감도를 제공한다. 어느 분석도 실패한 주 평가를 대체하지 않으며, 남은 모든 사건이 독립이라는 증거도 아니다.

## 실제 적용된 정정과 재현

새 전문 판정은 v6 개발 128건 + v6 평가 192건 + v7 평가 322건 = **642건**이다. 기존 358건은 제목·선두·증거 창 및 일부 전문을 읽은 이전 판정으로 입력 범위를 구분한다. 총 1,000건을 직접 AI 판정으로 표시하고 나머지 7,128건은 v5 모델 예측으로 명확히 표시한다. 직접 판정으로 덮은 점수의 자기 일치를 모델 정확도 개선으로 계산하지 않는다.

숫자 빈칸이 남은 SBS 방송 원고 1건은 값을 지어내지 않고 최종 연구용 자료에서 제외한다. 전체 8,128건을 점검했으며 적격 표시는 8,051→8,050건이다. 단위 앞 빈칸 감지의 누락을 단위시험으로 발견해 보완했고 전체 코퍼스를 재점검했지만 추가 표본은 발견되지 않았다. 이 개선은 봉인 모델이나 주 평가의 표본·예측을 바꾸지 않는다. 최초 고정 코드와 후속 품질 코드 모두 Git 이력에 남긴다.

`model.joblib` 원본은 학습 당시 `python -m`의 `__main__` 클래스 경로를 포함했다. 새 `model_portable.joblib`은 동일한 학습 객체를 import 가능한 경로로 다시 직렬화한 파일이다. 재학습·파라미터 변경은 없으며 원본 해시를 유지하고 8,128건 재추론으로 수치 일치를 검사한다.

```bash
# 기존 전문·특징 캐시가 있는 작업공간에서 실행
python -m news_flywire.risk_v6_evaluation
python -m news_flywire.risk_v7_evaluation evaluate
python scripts/check_risk_input_quality.py
python -m news_flywire.risk_release
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python scripts/audit_risk_evidence.py
python -m pytest -q
```

전체 전문과 특징 캐시는 Git에서 제외하며 공개 저장 자료에는 해시, 짧은 발췌, 직접 판정 근거, 예측과 오차, 선택·봉인 기록을 남긴다. 새 실제 AI 판정 없이 평가 표본을 다시 생성하거나 맞춘 뒤 원래의 미개봉 평가라고 주장할 수 없다. 결과 파일의 무결성 감사와 보고서 브라우저 검사도 최신 배포 폴더에 저장한다.
