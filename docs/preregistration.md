# 파일럿 분석 프로토콜 v0.1

이 파일은 실행 설정과 판단 기준을 기록하는 초안이며 외부 기관에 등록한 사전등록이 아니다. 현재 산출물은 가상 뉴스와 부분 회로의 계산 파일럿이다. 본실험은 실제 기사·독립 평가·보류 테스트를 확보한 뒤 별도 버전으로 고정한다.

- 주 입력은 정규화된 T 단독. N, A 및 가중치 (0.2,0.6,0.2)는 비교 변수다. 점수는 실제 스트레스 확률이 아니다.
- L/M/H 경계는 1/3, 2/3, 입력률은 30/80/150 Hz. 이 값은 생리 tuning curve로 보정하지 않은 가정이다.
- 커넥톰은 FAFB v783. LPLC2/LC4에서 GF/DNp06까지 최대 3 edge 경로의 노드를 선택하고 그 노드 사이의 연결을 모두 보존한다. 기본 최소 시냅스는 5개다.
- 입력은 210 LPLC2 + 104 LC4, 출력은 2 GF + 2 DNp06. 표적은 설정과 주석에서 확인하며 결과를 보고 선택하지 않는다.
- 실험은 E0~E9(E9a/b 포함 11조건), 30 시드, 첫 시드 20261109. 같은 시드의 고입력 조건에는 같은 외부 이벤트를 사용한다.
- E4는 비입력·비출력 세포에서 무작위로 같은 수를 선택한다. 감각 세포 매칭은 확보하지 못했다. 따라서 원제안서의 감각 세포 대조를 완전히 충족하지 않는다.
- E7은 LPLC2와 같은 수의 비입력·비출력 세포를 log(in/out degree) 거리 최소화로 선택한다. 역할·직접 자극 여부 및 연결 정도의 완전한 일치는 보장하지 않는다.
- 억제는 해당 세포의 시냅스 입출력을 제거한다. 직접 가해지는 외부 자극을 없애거나 실제 약물 효과를 모사한 것으로 부르지 않는다. 원본 Shiu 코드의 silence는 실제로 outgoing만 제거하며, 이 차이를 기록한다.
- LIF 상수는 원본에서 가져오지만 축소 엔진은 별도 구현이다. 해석적 subthreshold 갱신, 이산 지연, 이산 불응기를 사용한다. 기본 dt=0.5 ms에서 지연 1.8 ms는 2.0 ms로 근사한다.
- 주 결과는 출력 집단의 자극기 평균 발화율에서 기저 발화율을 뺀 값이다. 100 ms 기저/300 ms 자극/100 ms 회복. 단위는 Hz다.
- 잠복기는 첫 10 ms bin의 출력이 baseline+5 Hz에 도달한 시점의 bin 시작값이다. 0 ms는 첫 bin 내 반응이며 즉시 반응을 뜻하지 않는다. 미도달은 결측으로 보존한다.
- Recruitment는 비입력 뉴런의 Δ rate≥5 Hz. AUC는 baseline을 뺀 출력 Hz를 초 단위 적분한다. Recovery는 반응이 있었고 마지막까지 기준 ±5 Hz 이내인 최소 3개 bin이 남는 최초 시점으로 정의한다. 관찰창 내 미회복 또는 무반응은 미정의다.
- 평균/시드 표준편차, 대응 차이, 시드 bootstrap 95% 구간을 보고한다. 생물학적 p값을 계산하지 않는다.
- 민감도는 시냅스 임계 1/3/5, 입력률 배율 .75/1/1.25, dt .1/.5 ms를 계산 파일럿 3 시드로 비교한다. 주 결과를 대체하거나 유리한 설정을 선택하는 용도로 사용하지 않는다.
- 사람 평가 확보 후 T의 Spearman ρ 및 MAE, 서열형 α를 계산한다. 사건 단위 홀드아웃과 사건 군집 bootstrap을 사용한다. 제안 성공 기준 ρ≥.60은 아직 검증하지 않았다.
- 단순 입력률 증가에 따른 출력 증가는 새로운 생물학적 발견이 아니다. 모든 불일치·결측·실패 조건을 보존한다.
