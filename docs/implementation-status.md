# 구현·검증 상태

| 계획 항목 | 상태 | 근거 |
|---|---|---|
| 재현 가능한 저장소·설정·CLI | 구현·실행 | README, configs, manifest |
| N/T/A 분리 점수화 | 규칙 baseline 실행 | 24개 직접 작성 예시, news_scores.csv |
| LLM 구조화 점수·원자료 검증 | 가져오기 구현 | JSONL 스키마·고정 프롬프트; LLM 실행 미수행 |
| 실제 기사 240개·3인 사람 평가 | 미확보 | 빈 평가표와 기준서 제공 |
| 사람-AI 정확도·일치도 | 계산 코드 구현, 실자료 미평가 | evaluate, α·Spearman·MAE·군집 CI |
| v783 회로·실제 root ID | 확인·추출 | 1,367 neurons / 29,377 directed edges; paths.csv |

| 생리 보정된 시각 인코더 | 미검증 | 별도 physical renderer와 가상 Poisson 입력 구현 |
| E0~E9·억제·무작위 대조 | 330회 실행 | metrics, raw spikes, input events |
| 동등 총 입력량 | 외부 이벤트 수 정확히 일치 | E3/E4 및 억제 조건에 같은 이벤트 재사용 |
| 무작위 감각 세포 대조 | 부분 충족 | 현재 E4는 부분 회로 임의의 비입력/비출력 세포 |
| 동등 연결 정도 억제 | 근사 매칭 | 동일 수, log in/out degree 거리 최소화; 오차 기록 |
| 설정 민감도 | 6설정 × 3시드 × 11조건 | results/sensitivity |
| 독립 Brian2 수치 비교 | 소규모 고정 입력 회로 검증 | test_lif_reference.py; 전뇌 동등성 주장 아님 |
| 실제 뇌 활동과 비교 | 자료 목록 확인·비교 기능 구현 | DANDI 메타데이터; 대용량 영상 재분석 미수행 |
| 사람의 생리 반응 | 미수행 | 윤리·표본 수 계획 문서만 제공 |
| 분석 그림·보고서·원고·포스터 | 생성 | results/v783, docs/manuscript.md |

실제 연구의 최종 가설 검증은 미완료다. 실행 가능한 계산 파일럿과 외부 데이터 연동 기반을 제공하며, 실제 기사 라벨·보정 곡선·독립 신경 영상 자료가 들어오면 같은 절차로 확장할 수 있다. 모든 미확보·미수행 항목은 검증된 결과로 표시하지 않는다.
