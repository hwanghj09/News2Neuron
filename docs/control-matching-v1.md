# 출력 경로·전달물질을 맞춘 후속 입력 대조

**이전 GF 차이의 상당 부분은 대조군 구성에 민감했고, DNp06의 반대 반응은 보강 후에도 남았다.** 같은 실제 기사 8건·5시드에서 새 계산 120회를 수행했다. 이전 정상·무작위 조건 80회는 재사용임을 표시했으며 새 계산 수에 더하지 않았다.

## 확인하려던 문제

이전 실험에서는 무작위 입력이 GF 출력을 낮추면서 DNp06 출력을 높였다. 무작위 후보가 원래 감각 입력과 달라 생기는 차이인지 확인하기 위해, 원래 입력의 특징을 먼저 분석하고 대조군을 보강했다. 뉴스 점수·입력 함수·회로·뉴런 모델 파라미터는 바꾸지 않았다.

원래 입력 314개는 모두 **예측 전달물질**이 아세틸콜린이었다. 무작위 후보에는 GABA·글루타메이트 등도 있었고, GF와 DNp06까지의 최단 연결 수도 달랐다. 이 연결 수는 같은 v783 부분 그래프의 방향성 최단 hop이며 억제성 중간 뉴런을 지나는 경로도 포함한다. 실제 활성 전파 시간을 뜻하지 않는다.

## 정확하게 맞출 수 있는 범위

원래 입력과 출력 뉴런을 제외한 부분 회로 안에서 다른 뉴런을 찾았다. 두 출력까지의 hop 쌍과 예측 전달물질을 동시에 일치시키면 다음과 같다.

| GF hop | DNp06 hop | 원래 아세틸콜린 입력 | 다른 아세틸콜린 후보 | 공통 수 |
|---:|---:|---:|---:|---:|
| 1 | 1 | 38 | 59 | 38 |
| 1 | 2 | 150 | 14 | 14 |
| 2 | 1 | 59 | 376 | 59 |
| 2 | 2 | 67 | 162 | 67 |
| 합계 | | 314 | | **178** |

따라서 **이 부분 회로 안에서는 314개 전체를 중복 없이 정확하게 맞출 수 없다.** 부족한 뉴런을 중복하거나 새로 만들지 않고 두 비교를 분리했다.

1. **전체 314개 유지:** 전달물질은 모두 일치시킨 뒤, hop 차이·연결 수·절대 시냅스 강도를 근사 매칭했다. hop 쌍까지 정확한 비율은 54.14%다.
2. **공통 부분집합 178개:** 부족한 층에서 고정 시드로 원래 입력의 일부를 선택한다. 양쪽 뉴런의 hop 쌍과 예측 전달물질을 모두 일치시키고, 그 안에서 연결 수·시냅스 강도 차이를 줄인다.

178개 비교에서 원래 314개 이벤트 중 선택된 입력 슬롯의 이벤트만 추출해 새 슬롯으로 바꿨다. 이 **동일한 전체 배열**을 표적과 대조군에 사용했다. 중복 이벤트도 그대로 남겼다. 314개 근사 대조는 원래 R 이벤트 배열 전체를 사용한다.

연결 수와 강도는 log1p 후 전체 뉴런의 표준편차로 나눈 4개 특징(in/out degree, in/out absolute weight)의 거리로 매칭했다. 정확 매칭은 hop·전달물질 층에 대한 것이며 이 4개 특징까지 같은 것은 아니다. 평균 표준화 특징 거리는 공통 부분집합 1.23, 전체 근사 1.83으로 남았다.

설정·기사·뉴런 ID·매칭·원래 이벤트·회로·코드를 `b79d69b`에 먼저 고정한 후 새 출력을 계산했다. 같은 기존 잔존 위해 기사 8건 모두를 사용했고 결과를 보고 기사를 제외하거나 매칭을 고치지 않았다. 원래 기사 실험과 이전 보고서는 보존했다.

## 결과

단위는 출력 뉴런의 모델 ΔHz다. 기사별 5시드 평균을 먼저 구한 뒤 8개 기사를 평균했다.

**314개 입력을 유지한 비교**

| 조건 | GF | DNp06 | 계산 구분 |
|---|---:|---:|---|
| 원래 표적 입력 | 166.34 | 5.62 | 이전 결과 재사용 |
| 원래 무작위 입력 | 11.28 | 93.31 | 이전 결과 재사용 |
| 아세틸콜린·경로·연결 정도 근사 대조 | 139.31 | 104.69 | 새 계산 |

GF의 표적-대조 차이는 기존 155.06에서 27.03Hz로 줄었다. 원래 큰 차이를 표적 회로의 고유 특이성으로만 해석하기 어려워졌다. 여러 매칭 조건을 함께 바꿨으므로 어느 요인이 얼마만큼의 원인인지는 분리하지 못했다. 또한 전체 314개에서는 경로 매칭이 불완전하다.

**178개 공통 부분집합 비교**

| 조건 | GF | DNp06 |
|---|---:|---:|
| 선택된 원래 입력 178개 | 104.53 | 21.28 |
| hop 쌍·예측 전달물질이 같은 다른 178개 | 73.34 | 122.47 |

DNp06의 반대 방향 차이는 정확한 hop·전달물질 층 매칭에서도 사라지지 않았다. 대조-표적 차이는 +101.19Hz였고, GF는 −31.19Hz였다. 해당 기사 8건의 시드 평균을 재표집한 기술적 범위는 각각 +90.84~112.81Hz, −35.31~−27.19Hz다. 이는 생물학적 반복이나 모집단의 신뢰구간이 아니다.

178개로 줄이면 표적 구성도 달라진다. 시드별 LPLC2는 144~149개, LC4는 29~34개다. 원래 314개 전체의 구성을 대표한다고 보지 않으며, 178개와 314개 결과의 절대 크기를 직접 비교해 매칭 효과라고 부르지 않는다.

## 해석 범위

보강 대조군도 중간 뉴런이며 감각 세포형까지 맞추지 못했다. 총 연결 강도를 근사 매칭해도 특정 출력으로 가는 직접 연결 강도, 흥분·억제 경로, 피드백, 수용체 등은 다르다. 전달물질은 예측 주석이며 측정된 수용체 효과가 아니다.

따라서 이번 단계는 **단순한 무작위 세포 대조가 충분하지 않았음을 보여주는 계산 검증**이다. GF/DNp06의 실제 생물학적 위협 선택성, 뉴스 의미 이해, 사람의 스트레스 반응을 입증하지 않는다. DNp06 차이의 구체적 원인은 아직 미확인이다.

## 재현·원자료

```bash
news-flywire controls-prepare --out results/my_matched_controls
news-flywire controls-run --out results/my_matched_controls
news-flywire controls-report --out results/my_matched_controls
python scripts/audit_matched_controls.py
python -m pytest -q
```

부모 실행은 `configs/control_matching_v1.yaml`에 지정한다. 새 폴더에서 준비하고, 봉인 파일이 바뀌거나 완료된 결과에 다시 실행하려 하면 중단한다. 같은 부모의 스냅샷과 회로를 쓰므로 새 뉴스 판정이나 개인 원문 캐시 없이 재현할 수 있다.

전체 테스트 **140개 통과**. 매칭의 disjoint·중복 없음·hop/전달물질 일치·난수 재현성·부족한 후보의 실패 처리·이벤트 중복 보존을 검사했다. 원자료 감사는 5개 시드의 매칭을 재생성하고, 40개 기사×시드 이벤트 쌍, 120회 스파이크 기반 지표, 대표 3회 네트워크 실행의 스파이크 시점·ID 전체 일치를 확인했다.

`all_output_types.csv`의 `fresh_simulation`으로 새120회와 재사용80회를 구분한다. `controls.json`에는 뉴런 ID·원래 슬롯·잔여 오차, `neuron_signatures.csv`에는 경로·연결 특징, `trials/기사ID/`에는 새 이벤트·스파이크·지표·해시가 있다. 입력 뉴런 178개나 계산 시드 5개를 생물학적 독립 표본 수로 세지 않았다.

지표 주의: `metrics.csv`의 recruitment는 기존 엔진의 원래 input 역할 제외 기준이다. 대조군에서 새로 자극한 중간 뉴런은 포함될 수 있어 이 단계의 대조군 간 recruitment 비교를 결론 근거로 사용하지 않았다. 주 비교는 GF·DNp06의 출력 발화율이다.
