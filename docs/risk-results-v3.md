# 뉴스 위험성 평가 v3 실행 결과

사람 평가를 기다리지 않고 현재 Codex가 실제 기사 198건을 직접 판단했다. 학습 보정에는 129건을 사용했고, 이를 근거로 전체 8,128건의 본문 의미 예측을 세 차례 수정했다. 직접 읽은 판단과 모델이 일반화한 예측은 파일과 화면에서 구분한다.

- 학습 보정: 65 → 97 → 129건. 10월 11일까지의 학습 기사만 사용했다.
- 고정 AI 감사: 매체별 6건씩 48건. 학습·정규화 강도 선택에 사용하지 않았다.
- 중대 피해·오탐 목적 표본: 매체별 2건씩 16건. 모집단 추정 표본이 아니다.
- 추가 품질 판정: 홍보문 제거 후 짧아진 실제 본문 5건을 전부 직접 읽었다.

## 수치 변화

위험 지수는 [기준서](risk-rubric-v3.md)의 0~100 지수다. 아래는 직접 판정으로 교체하기 전 모델 출력과 같은 세션 AI 판정 사이의 평균 절대오차(MAE)이며, 독립 정답 정확도·발생 확률·생리 반응 오차가 아니다.

| 모델 회차 | 개발 판정 수 | 고정 48건 위험 지수 MAE | 목적 표본 16건 MAE | 고정 48건 T MAE /4 |
|---|---:|---:|---:|---:|
| 1 | 65 | 10.52 | 18.73 | 0.758 |
| 2 | 97 | 9.91 | 17.65 | 0.730 |
| 3 | 129 | 9.23 | 17.13 | 0.686 |

평균 오차는 감소했지만 고정 감사에서 최대 49.23점의 개별 오차가 남았다. 최종 점수표에서 직접 읽은 198건은 직접 판정을 제공하고, 나머지는 모델 예측임을 명시한다. 낮은 평균 오차를 모든 기사에 대한 완벽함으로 해석하지 않는다. 기사별 오차는 [감사 오류 원장](../data/risk/20261109_v3/audit_errors.csv)에, 매체별 값은 별도 CSV에 공개한다.

원래 단어 규칙의 고정 감사 N/T/A MAE는 각각 1.167/0.917/1.292이며 v3 최종 모델은 0.616/0.686/0.555다. 이는 v3의 같은 AI 기준에 대한 비교이며 사람 정답에 대한 정확도 증가율이 아니다. 원래 규칙과 수정 입력을 맞춘 비교도 JSON에 남긴다.

## 입력 자료를 다시 고친 내용

최종 감사에서 서울신문의 `sportLightPromotion` HTML 위젯이 다른 홍보기사의 전문을 본문 중간에 넣는 문제를 발견했다. 서울신문 전체 응답을 같은 DOM 규칙으로 검사해 180건의 삽입물을 제거했다. 원래 기사에서 홍보문 전후의 서술은 모두 유지했다.

영향을 받은 학습 기사는 0건이다. 학습 행렬·모델 가중치·정규화 강도는 바꾸지 않았고, 수정된 180건만 같은 고정 모델로 다시 추론했다. 원래 봉인 예측과 `input_corrected_predictions.parquet`를 따로 보존한다. 전처리 수정이 감사에서 발견됐으므로, 전처리까지 완전히 손대지 않은 테스트라고 주장하지 않는다. 정제 전 오차도 `original_pre_input_repair_rounds`로 공개한다.

5건은 정제 후 실제 본문이 400자 미만이었다. 이 5건은 탐색용 직접 AI 점수를 제공하되 연구용 분석에서 제외한다. 기존의 평가 중복·늦은 수정·협찬 의심 제외와 함께 적용한 연구용 자료는 **8,051건**이다. 원래 v2 코퍼스는 수정하지 않으며 `body_sha256`과 `assessment_body_sha256`로 원본과 평가 본문을 구분한다.

## 검증 범위와 남는 불확실성

전체 8,128건의 본문 해시, 토큰 넘침 창의 끝까지의 내용 복원, CSV/Parquet 수치 일치, 직접 판정 ID·본문 결합, 세 회차의 학습·감사 분리, 홍보문 제거 전후 본문과 고정 모델 해시를 감사했다. 이는 출처·계산·처리의 검증이며 뉴스 사실이나 의미 판단의 완전한 정확도를 입증하는 절차는 아니다.

고정 감사 중 1건은 학습 기사와 같은 공항 공격의 후속 보도임을 직접 확인했다. 기사 ID와 자동 사건 후보 그룹은 다르지만 의미적으로 전혀 새로운 사건만으로 구성된 감사는 아니다. 또한 시간상 학습 구간에는 5개 매체만 있어 나머지 매체는 출처 변화의 영향도 받는다.

모델은 고정 revision의 multilingual-e5-small 의미 특징, 학습된 문맥 단서, Ridge 서열 회귀를 사용했다. 12개 사건 후보 그룹 부트스트랩의 범위는 재학습 민감도이며 보장된 신뢰구간이 아니다. 최종 보고서의 추가 AI 검토 후보 169건과 원장으로 다음 실제 판단을 이어갈 수 있다. 새 판단 없이 자동 반복만으로 평가자가 늘어나거나 점수가 검증된 것으로 처리하지 않는다.
