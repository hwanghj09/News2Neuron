**뉴스 점수 보정 다음 단계인 실제 기사별 회로 실험을 구현하고 실행했다.** 최신 8,128건의 점수를 자극 파라미터로 변환했고, 8개 매체의 실제 기사 24건에 대해 7조건×5시드 840회와 무입력 대조 5회, 총 **845회의 새 시뮬레이션**을 수행했다. 이전의 3단계 결과 조회는 사용하지 않았다.

## 이전 단계와 실제 차이

이전 `analyze-news`는 T를 L/M/H로 나눠 이미 실행된 E1/E2/E3 결과를 기사에 연결했다. 같은 단계의 기사는 같은 반응 분포를 공유했고, T=0도 30Hz를 입력했다. 이 방식은 초기 파일럿으로 보존한다.

이번 파이프라인은 다음을 새로 수행한다.

1. 기존 1,032건 스냅샷과 추가 판정 42건을 합쳐 최신 8,128건을 구성한다. 직접 판정은 1,074건이며 나머지는 기존 v5 예측이다. 연구용 제외·미완성 초안 등 78건은 신경 입력률을 비워 두고 실행 대상에서 제외한다.
2. 3단계 구간 대신 연속 점수를 사용한다. R은 잔존 위해 지수/100, T와 N은 기존 정규화 축이다. R을 주 변환으로 쓰고 T·N을 별도 비교한다. R=0이면 입력은 0Hz다.
3. 기사 ID와 계산 시드로 고정된 난수열을 만들어 기사별 Poisson 이벤트를 생성한다. 양수 점수가 같아도 서로 다른 기사의 이벤트를 공유하지 않는다. R/T/N은 같은 제안 이벤트를 thinning해 짝지어 비교한다.
4. 실제 v783 부분 회로에서 각 기사·조건을 새로 실행한다. 입력 이벤트, 원래 스파이크, 세포별 지표, 출력 시간 곡선, 물리 곡선과 파일 해시를 저장한다.

8,128건 모두에 뇌 반응을 계산한 것은 아니다. **전체는 입력 파라미터를 생성했고, 새로운 신경 계산은 24건에 실행했다.**

## 자극 변환의 정의

설정은 [article_bridge_v1.yaml](../configs/article_bridge_v1.yaml)에 있다. 물리적 원판과 신경 입력은 가정한 변환으로 연결하며, 측정된 시각 뉴런 tuning curve로 보정된 관계는 아니다.

- 원판 반지름 0.01m, 시작 각도 20°, 최종 각도 80°를 고정한다. 자극 시간은 공통 400ms이며 접근 끝을 자극 끝에 맞춘다. 무입력은 원판이 20°로 정지한다.
- 정규화 점수를 s라 하면 `l/v = 80−60s ms`, 속도는 `반지름 / (l/v)`다. 거리가 양수인 등속 접근의 `θ=2 arctan(반지름/거리)`를 계산한다. 접근 전체가 400ms 안에 들어가지 않으면 거부한다.
- 평균 외부 입력률은 `150s Hz`다. 양수 입력률의 80%는 균일하고, 20%는 각도 증가량에 비례한다. 전체 시간에서 평균을 보존하므로 시각적 접근 속도가 기대 총 입력량을 임의로 바꾸지 않는다.
- 650Hz 제안 Poisson 과정에서 실제 시간별 입력률로 thinning한다. 제안률이 실제 곡선을 덮지 못하면 중단하며 몰래 clipping하지 않는다. 같은 시간·세포에 겹친 이벤트도 제거하지 않는다.
- 시뮬레이션은 자극 전 100ms, 자극 400ms, 회복 100ms, dt=.5ms다. 물리 곡선과 신경 입력의 제시 시간을 맞췄다. 기존 연구 설정·결과 파일은 바꾸지 않았다.

이 평균 입력률과 80/20 혼합은 연구 설계 선택이다. 실제 신경 반응·심리적 긴장·스트레스 확률의 척도가 아니다. 0점에서 모델이 반응하지 않는 것도 이 설정의 결과다.

## 선정과 대조 조건

실행 전에 설정·코드·기사·입력 표·회로 파일 해시를 `363a811`에 봉인했다. 결과를 보고 기사를 바꾸지 않았다. 각 그룹에서 매체별 1건씩 선택해 24건을 만들었고, 자동 사건 가족은 서로 다르도록 했다.

| 기사군 | 선정 기준 | 기사 수 |
|---|---|---:|
| 낮은 부정·위험 | N≤.25, R 지수<10 | 8 |
| 부정적이지만 종결 | N≥.75, R=0, 상태 resolved/retrospective | 8 |
| 잔존 위해 | R 지수≥30, T≥.5 | 8 |

모두 직접 AI 판정이 있는 실제 기사다. 기존 판정에는 전문 판정뿐 아니라 초기 제목·선두·증거 창 중심 판정도 포함되므로, 이 단계에서 24건의 전문을 새로 독립 판정했다는 주장은 하지 않는다. AI 기준 자체와 연결 함수의 불확실성은 남아 있다.

| 조건 | 입력·조작 |
|---|---|
| R_intact | R에 따른 입력, 정상 연결 |
| R_random_input | 같은 R 이벤트를 같은 수의 무작위 세포에 입력 |
| R_LPLC2_cut | 같은 R 이벤트, LPLC2 210개의 입출력 연결 제거 |
| R_LC4_cut | 같은 R 이벤트, LC4 104개의 입출력 연결 제거 |
| R_degree_cut | 같은 R 이벤트, LPLC2와 수·연결 정도를 근사 매칭한 210개 세포의 입출력 연결 제거 |
| T_intact | 같은 기사에서 T에 따른 입력, 정상 연결 |
| N_intact | 같은 기사에서 N에 따른 입력, 정상 연결 |

각 기사의 R 대조 5조건은 **외부 이벤트의 수·시점·입력 슬롯 배열 전체가 동일**하다. 무작위 입력에서는 슬롯에 대응하는 뉴런만 바꾼다. R/T/N은 기대 입력량과 시간 형태가 달라질 수 있으므로 같은 입력량 대조로 취급하지 않는다.

뉴런은 실제 FAFB v783의 LPLC2·LC4 입력과 GF·DNp06 출력을 포함한 1,367개, 방향성 연결은 29,377개다. 원래 Shiu 모델의 상수를 쓰는 별도 부분 회로 LIF 엔진이며 전뇌 실행이나 실제 활동 측정이 아니다.

## 실행 결과

아래 값은 먼저 기사별 5시드의 평균을 낸 뒤 8개 기사를 평균한 모델 출력 ΔHz다. 출력은 GF 2개·DNp06 2개 평균이다.

| 기사군 | R 입력 | T 입력 | N 입력 |
|---|---:|---:|---:|
| 낮은 부정·위험 | 6.75 | 15.95 | 31.98 |
| 부정적이지만 종결 | 0.00 | 0.00 | 122.16 |
| 잔존 위해 | 85.98 | 103.59 | 106.69 |

종결 기사에서 R/T가 0이고 N이 높으면 이처럼 다른 입력을 준다. 이는 변환 정의에서 따라오는 모델 내부 결과이며 뇌가 사별·뉴스 의미·위협을 구분했다는 증거가 아니다.

잔존 위해 8건에서 동일 R 이벤트를 사용한 결과는 다음과 같다.

| 조건 | 전체 출력 ΔHz | GF ΔHz | DNp06 ΔHz |
|---|---:|---:|---:|
| 정상 연결 | 85.98 | 166.34 | 5.62 |
| 무작위 입력 | 52.30 | 11.28 | 93.31 |
| LPLC2 연결 제거 | 23.84 | 47.69 | 0.00 |
| LC4 연결 제거 | 80.58 | 148.47 | 12.69 |
| 연결 정도 매칭 대조 | 85.98 | 166.34 | 5.62 |

**평균 출력만으로 회로 특이성을 결론 낼 수 없다.** LPLC2 연결 제거는 감소를 보이지만, DNp06은 무작위 입력에서 더 크게 반응했다. LC4 차단도 모든 출력에서 같은 방향이 아니다. 무작위 세포는 감각 세포형까지 매칭하지 않았고, 연결 정도 매칭도 잔여 오차가 있는 근사다. 이 대조군과 부분 회로 하나로 생물학적 위협 회로 특이성이 입증됐다고 보지 않는다.

[짝지은 비교](../results/article_bridge_v1/paired_comparisons.csv)는 기사별 시드 평균을 비교한다. 기사 단위 재표집 범위는 이 의도적으로 고른 기사 집합의 변동을 설명하는 기술 통계다. 생물학적 반복이나 사람 반응의 신뢰구간이 아니다. 같은 점수에서 입력이 강해져 출력이 커지는 것 자체도 새로운 생리학적 발견이 아니다.

## 사용

```bash
# 같은 실험을 새 폴더에 재현
news-flywire bridge-prepare --out results/my_article_bridge
news-flywire bridge-run --out results/my_article_bridge
news-flywire bridge-report --out results/my_article_bridge

# 이미 저장된 원자료와 모델의 재현 검사
python scripts/audit_article_bridge.py --out results/article_bridge_v1
python -m pytest -q
```

완료된 실행은 덮어쓰지 않는다. 중간 중단 시 `bridge-run`은 완료된 기사 체크포인트의 파일 해시를 검증하고 남은 기사만 계산한다. 완료된 결과의 보고서는 `bridge-report`로 다시 만들 수 있다. 준비 후 점수 원장·설정·회로·실험 소스가 바뀌면 봉인 검사가 실패하므로 새 출력 폴더에서 시작해야 한다.

## 검증과 원자료

전체 테스트 **137개 통과**. 새 테스트는 물리적 각도·거리 관계, 공통 제시 시간, 기대 입력량 보존, 제안률 상한, 기사별 난수 재현성, 0점 무입력, 시간별 Poisson 수, 품질 제외를 검사한다. 기존 Brian2 수치 비교·뉴스 데이터 테스트도 유지한다.

감사에서는 다음을 확인했다.

- 원자료 파일·코드·점수·회로 해시 및 24건의 점수 출처·고유 사건 가족
- 360개의 R/T/N 원래 이벤트 배열 재생성과 120개의 기사×시드 R 대조 배열 완전 일치
- 원래 스파이크로 기사 실험 840회의 지표 재계산
- 정상·LPLC2 차단·무작위 입력·T 입력의 대표 4개 네트워크 실행에서 스파이크 시점·뉴런 전체 일치
- 중복 이벤트 67,367개가 제거되지 않고 보존됨
- 전체 845회 중 외부 입력이 양수인 기사 실험은 400회이며, 나머지는 0입력 실험임을 구별

`trials/기사ID/`에는 `events.parquet`, `spikes.parquet`, `cells.parquet`, `curves.parquet`, `stimulus_profiles.parquet`, `metrics.csv`, `receipt.json`이 있다. 이벤트 파일은 R/T/N별 한 배열을 저장하고, 회로 대조 조건들이 R 배열을 공유한다. 무입력 5회의 지표는 별도 `baseline_metrics.csv`에 있다. 감사의 재실행은 원래 845회 수에 더하지 않았다.

보고서는 인터넷 없이 열 수 있다. 물리 곡선은 화면에서 10ms 간격으로 표시하며 전체 .5ms 곡선은 Parquet에 보존한다. 출력 시간 곡선은 10ms bin·5시드 평균이다. 저장된 잠복기는 threshold를 처음 넘은 bin의 시작점이어서 0ms로 표시돼도 전파 지연이 실제로 0이라는 뜻이 아니다.

배포 경로 정리: 다른 체크아웃에서도 기존 실험을 감사할 수 있도록 프로토콜의 저장소 내부 절대 경로를 상대 경로로 정리했다. 봉인 당시 원문은 `protocol_original.json`, 원래 실행 원장은 `run_manifest_original.json`에 그대로 보존하고 `path_packaging.json`에 이전·이후 해시를 남겼다. 설정·기사·코드의 내용 해시와 신경 계산 결과는 바꾸지 않았다. 새 실행도 필요하면 `python scripts/normalize_bridge_paths.py --out results/my_article_bridge`로 같은 정리를 할 수 있다.
