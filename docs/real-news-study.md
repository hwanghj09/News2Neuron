# 실제 뉴스 평가 파일럿 — 2026-11-09

## 확보·평가한 자료

공식 RSS를 통해 **실제 기사 240건**을 수집하고, 제목과 짧은 공개 발췌문을 현재 Codex 세션에서 N/T/A로 평가했다. 원문 전체를 평가하거나 기사에 적힌 주장 자체의 사실 여부를 검증한 것은 아니다.

| 매체 | 기사 수 |
|---|---:|
| 연합뉴스 | 92 |
| SBS | 72 |
| MBN | 76 |

경제·사회·국제·문화·스포츠·생활/건강 RSS 분야를 각 40건씩 선택했다. 발행 범위는 2026-10-28~2026-11-09(UTC)다. 분야 안에서 매체별 최신 기사를 돌아가며 선택한 편의표본이다. 원계획의 재난·중립·긍정 등 **정서 범주 균형을 확보한 표본은 아니다.** 매체의 문화 분야에 날씨가, 생활/건강 분야에 문화·기업 소식이 들어 있는 경우도 유지하고 출처 분류임을 표시했다.

제목·발췌문 인용 합계는 기사당 최대 25개 공백 단위 단어다. 완전한 원문이나 RSS의 `content:encoded` 필드는 공개하지 않는다. 발췌문은 출처가 작성한 텍스트이며 연구자가 직접 작성한 요약이라고 표시하지 않는다. 길이가 짧거나 문장 중간에 끊기는 자료가 있어 제목의 영향을 크게 받을 수 있다. 당시 RSS 원본은 공개 Git에서 제외한 `data/raw/news_rss/`에 보관하고 응답 해시를 기록했다.

## 점수의 출처

- 주 평가: `codex_session_nta_v1_20261109`. 이 대화에서 실제 제목·발췌문을 읽고 기사별 N/T/A 0~4와 근거를 기록했다. 소수점 0~1 값은 원점수를 4로 나눈 것이다.
- 정확한 공급자 모델 스냅샷과 디코딩 온도는 세션에 노출되지 않았다. API 모델 버전이나 temperature=0으로 실행했다고 주장하지 않는다.
- JSONL과 원래 결정 TSV, 기사별 텍스트 해시를 모두 보존한다. `finalize_real_news_ratings.py`는 기록된 판단을 정형화하는 스크립트이며 LLM을 새로 호출하는 코드가 아니다. 다른 기사나 순서에 같은 판단을 적용하지 못하도록 입력 스냅샷을 검증한다.
- confidence는 null이다. 독립 사람 평가자는 0명이며 사람 합의 정답·정확도·신뢰구간은 아직 없다.
- 비교 평가: 원래의 `rule_baseline_v1`을 동일한 제목·발췌문에 적용했다. 두 AI 접근의 상관·차이는 **사람 정답에 대한 정확도나 오류가 아니다.**
- T는 기사 발행 당시 서술의 구체성·심각성·임박성을 평가한다. 과거 기상 기사 점수는 현재 유효한 경보가 아니다. P(개인적 관련성), 실제 각성·스트레스·호르몬은 추정하지 않는다.

예를 들어 해킹·부정결제 기사와 해상 풍랑주의보는 문맥 평가와 단어 규칙 사이에 차이가 있었다. 반대로 공연·스포츠 기록은 각성 가능성이 있더라도 실제 위해로 읽지 않았다. 이런 차이를 검토할 수 있도록 기사별 근거와 두 점수를 함께 제공한다. 문맥 평가가 더 정확하다는 결론은 독립 정답 확보 전에는 내리지 않는다.

## 사건 묶음과 사람 평가 준비

문자 n-gram 유사도 후보와 이번 세션에서 확인한 후속 보도 태그를 합쳐 146개의 보수적인 사건 그룹을 만들었다. 복수 사건을 다루는 종합 헤드라인은 관련 그룹을 연결했고, 기업 관련 연속 보도는 더 넓은 묶음으로 보존했다. 서로 다른 사건이 과하게 묶일 수 있으며 독립 사람의 사건 감사는 아직 없다.

고정 분할은 개발 186건·테스트 54건이며 사건 그룹은 분할 사이에 겹치지 않는다. 기사당 3인 빈 평가표 720행을 별도로 만들었다. **빈 양식은 사람 레이블이 아니다.** 본실험 전에는 사람이 중복·사건 묶음·표본 구성을 점검하고 실제로 독립 평가해야 한다.

## 회로 출력 연결

T 단계는 L 181건·M 40건·H 19건이다. 기존 `results/v783`에서 계산한 E1/E2/E3의 30시드 결과를 해당 단계의 기사에 연결해 7,200행을 만들었다. 같은 단계는 같은 모델 출력 분포를 공유한다. 기사별로 7,200개의 새로운 독립 뇌 시뮬레이션을 수행한 것이 아니다.

T=0도 사전 정의된 L(30 Hz) 입력으로 변환되며 무입력 E0와 다르다. 따라서 모델 출력은 실제 뉴스 스트레스 수치나 새로운 생물학적 예측의 독립 증거가 아니다.

## 재현 명령

```bash
# 기본 score는 이제 실제 기사 240건에 규칙 baseline을 적용한다
news-flywire score

# 보존된 문맥 판단을 다시 가져오기: LLM을 새로 호출하지 않는다
news-flywire score --news data/real_news/2026-11-09/news.csv \
  --llm-jsonl data/real_news/2026-11-09/ratings/codex_nta_v1.jsonl \
  --model codex_session_nta_v1_20261109 --out data/derived/my_real_news_scores.csv

# 새 폴더에 실제 뉴스 보고서 생성; 기존 단계별 계산을 재사용한다
news-flywire analyze-news --out results/my_real_news_report

# 이후 새 기사는 별도 수집하고 별도로 평가해야 한다
news-flywire collect-news --out data/real_news/my_new_collection
```

공식 피드는 시간이 지나면 내용이 바뀐다. 같은 URL을 나중에 재수집해 2026-11-09의 원본 응답과 같다고 간주하지 않는다. 공개 저장소에는 실제 평가한 텍스트 스냅샷·기사 URL·발행일·해시·점수·근거를 제공한다. [실제 뉴스 보고서](../results/real_news_20261109/report.html)에서 검색·분야·매체·T 필터와 다운로드를 사용할 수 있다.
