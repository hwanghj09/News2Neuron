# 독립 뉴스 평가 기준서 v1

기사 제목과 100~300자 요약을 읽고 N/T/A를 각각 0~4의 정수로 평가한다. 평가자는 서로의 응답과 모델의 점수를 보지 않는다. 제시된 기사가 현재 평가자 자신에게 미치는 생리 반응을 측정하는 절차는 아니다.

| 점수 | N: 부정성 | T: 위협성 | A: 예상 정서적 각성 |
|---|---|---|---|
| 0 | 부정적 사건·논조 없음 | 명백한 위험 신호 없음 | 정서 반응 가능성 매우 낮음 |
| 1 | 약한 불편·아쉬움 | 경미하거나 먼 위험 | 약한 반응 가능성 |
| 2 | 분명한 부정적 결과 | 잠재적 위험 | 중간 정도 반응 가능성 |
| 3 | 중대한 손실·슬픔 | 중대하고 구체적인 위험 | 강한 반응 가능성 |
| 4 | 매우 심각한 부정적 사건 | 임박하거나 매우 심각한 위해 가능성 | 매우 강한 반응 가능성 |

사별·추모가 N에서 높더라도 즉각적 T는 낮을 수 있다. 경제·사회적 위해도 T에 포함하되 `notes`에 신체/경제/사회 위험을 구별한다. 즐거운 우승 소식도 A는 높을 수 있다. P(개인적 관련성)는 기사 자체에서 추정하지 않는다.

`data/labels/ratings_template.csv`의 `rater_1/2/3`은 빈 작업 양식이다. 실제 독립 평가자 식별자로 바꾼다. 동의 없는 개인정보를 입력하지 않는다. 각 기사당 최소 3명, 각 평가자·기사 쌍은 한 행만 사용한다. 실제 점수 없이 빈칸을 자동 채우지 않는다.

합의는 축별 중위값/4로 정규화하며 원자료를 보존한다. 불일치 원인은 notes에 남기고 사람 합의와 개별 점수를 함께 저장한다. `evaluate`는 고정 테스트 세트에서만 오차를 계산하고 서열형 Krippendorff α를 전체 독립 평가 자료에서 보고한다.

현재 24개 가상 기사는 코드 점검용이다. 목표 240건의 실제 기사 표본이나 사람 평가 자료를 대신하지 않는다. 실제 뉴스 수집 시 동일 사건을 event_group으로 묶고 제목 유사도와 재송고를 수동 점검한 뒤 분할을 고정한다.
